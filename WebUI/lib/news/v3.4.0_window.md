# v3.4.0 更新：独立窗口系统

**发布日期**：2026-10-15

## 独立窗口

存档管理、工具中心改为独立窗口弹出，不再占用主窗口空间。

## 模态遮罩

打开独立窗口时主窗口显示半透明遮罩（0.7 黑色 + 0.3s 淡入淡出），聚焦当前操作。

## 窗口位置记忆

- 登录器启动位置自动记录，下次恢复
- 独立窗口在主窗口当前位置居中启动

## 透明度效果

- 独立窗口 98% 透明度（分层窗口 alpha=250）
- 毛玻璃风格，视觉层次更清晰

## 工具中心优化

- 移除窗口内标题、副标题
- 控件垂直居中
- 独立窗口标题字号调整为 16px
- 移除独立窗口状态栏，更简洁

## 技术细节

- 独立窗口使用分层窗口（WS_EX_LAYERED）控制透明度
- DWM 阴影与透明度共存
- 主窗口与独立窗口通过 Python API 双向通信
