# v3.4.0 更新：WebView 架构重构

**发布日期**：2026-10-15

## 架构升级

从 Qt/PyQt5 全面迁移到 pywebview + WebView2 渲染引擎，告别传统 Qt 控件的限制。

## 全新界面

- 全屏背景图 + 毛玻璃登录卡片 + 左下角新闻面板
- 登录卡片点击设置翻转到服务端设置
- 导航栏移至标题栏横置（服务端/存档/工具）
- DNF Logo 左上角展示，hover 放大效果

## 服务端管理

- 服务端下拉菜单：启动/重启/停止/查看日志
- 标题栏实时显示服务端状态

## 窗口效果

- 无边框窗口 + DWM 阴影 + 圆角
- 思源黑体字体加载
- CSS -webkit-app-region 窗口拖动
