# WebView 登录器全新上线

轮回登录器迎来重大更新！全新 WebView 架构版本正式发布。

## 全新架构

采用 pywebview + WebView2 渲染引擎，告别传统 Qt 控件的限制，带来更流畅的视觉体验。

## 核心亮点

- **游戏级视觉**：全屏背景图 + 毛玻璃卡片，沉浸式体验
- **自定义背景**：支持更换个人背景图，最多 8 张轮播
- **丝滑动画**：背景切换淡入淡出，卡片翻转过渡
- **主题菜单**：上一张/下一张快捷切换，高级设置管理背景
- **独立窗口**：存档管理、工具中心以独立窗口弹出，主窗口模态遮罩

## 技术升级

- 渲染引擎：WebView2（基于 Chromium）
- 窗口方案：无边框 + DWM 阴影 + 圆角
- 样式系统：CSS 变量 + 毛玻璃滤镜
- 通信方式：JS ↔ Python 双向调用

全新体验，等你探索！
