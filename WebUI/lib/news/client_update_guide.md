# 客户端更新与文件校验说明

## 客户端更新

### 自动更新

登录器支持客户端自动更新功能：

1. 启动登录器后，自动检测客户端版本
2. 如有更新，状态栏会提示「客户端有新版本可用」
3. 点击通知或在工具中心选择「客户端补丁」进行更新
4. 更新过程中请勿关闭程序

### 手动更新

如自动更新失败，可手动更新：

1. 下载最新客户端补丁包
2. 关闭游戏和登录器
3. 将补丁文件解压到客户端根目录
4. 覆盖同名文件
5. 重新启动登录器

### 更新注意事项

- 更新前建议备份客户端目录
- 确保磁盘空间充足（至少 2GB 可用）
- 更新过程中不要中断
- 如更新失败，可使用备份恢复

## 文件校验

### 校验功能

登录器提供客户端文件校验功能，确保游戏文件完整：

1. 打开工具中心（导航栏→工具）
2. 选择「PVF校验」或「文件校验」
3. 选择校验类型（完整校验/快速校验）
4. 等待校验完成

### 校验类型

**快速校验**
- 仅校验关键文件（PVF、EXE、DLL）
- 耗时较短（约 1-2 分钟）
- 适合日常检查

**完整校验**
- 校验客户端所有文件
- 耗时较长（约 5-10 分钟）
- 适合怀疑文件损坏时使用

### 校验结果说明

| 结果 | 含义 | 处理方式 |
|------|------|----------|
| 通过 | 所有文件完整 | 无需处理 |
| 缺失 | 有文件丢失 | 重新安装或恢复备份 |
| 损坏 | 文件校验失败 | 重新下载对应文件 |
| 版本不符 | 文件版本不匹配 | 更新客户端 |

### 校验失败处理

如校验发现文件异常：

1. **记录异常文件列表**
2. **尝试自动修复**（如支持）
3. **手动恢复**：从备份或安装包中提取对应文件
4. **重新安装**：如大量文件异常，建议重新安装客户端

## PVF 文件说明

### 什么是 PVF

PVF（Package File）是 DNF 游戏的资源包文件，包含游戏内所有素材（图片、音频、脚本等）。

### PVF 校验

PVF 校验用于检查游戏资源包是否完整：

1. 打开工具中心
2. 选择「PVF校验」
3. 选择要校验的 PVF 文件
4. 等待校验完成

### PVF 修改注意事项

- 修改 PVF 前务必备份原文件
- 使用专业工具修改（如 PVF 编辑器）
- 修改后需重新校验
- 如修改导致游戏崩溃，恢复备份

## 常见问题

**Q: 校验一直卡在某个文件？**
A: 该文件可能较大或磁盘读取较慢，请耐心等待。如超过 30 分钟无响应，可取消后重试。

**Q: 更新后游戏闪退？**
A: 可能是更新不完整或文件冲突：
1. 运行文件校验
2. 如发现异常，恢复备份
3. 重新执行更新

**Q: 如何关闭自动更新？**
A: 在登录器设置中可关闭自动更新检测。关闭后需手动检查更新。

**Q: 校验时可以玩游戏吗？**
A: 不建议。校验过程中会读取大量文件，可能影响游戏性能，且游戏运行时文件被占用可能导致校验失败。
