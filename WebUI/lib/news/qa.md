# 常见问题 Q&A

## 程序启动

**Q: 程序打不开/闪退怎么办？**
A: 请尝试以下方法：
1. 确认系统已安装 WebView2 运行时（Win10/11 通常自带）
2. 以管理员身份运行
3. 删除程序目录下的 `window_config.json` 后重新启动
4. 检查杀毒软件是否隔离了程序文件

**Q: 程序界面显示异常怎么办？**
A: 
1. 确认系统缩放为 100%（设置→系统→显示→缩放）
2. 更新显卡驱动
3. 确认 WebView2 版本为最新

---

## 服务端

**Q: 服务端启动失败？**
A: 
1. 检查服务端路径设置是否正确（应指向服务端根目录）
2. 确认端口未被占用
3. 查看服务端日志（服务端→查看日志）
4. 确认数据库服务已启动（MySQL 模式）

**Q: 标题栏显示「服务端未连接」？**
A: 
1. 点击「服务端」→「启动」
2. 等待 5-10 秒，服务端启动需要时间
3. 如仍未连接，检查服务端路径和端口配置

---

## 登录游戏

**Q: 点击登录没反应？**
A: 
1. 确认服务端已启动（标题栏显示「服务端已启动」）
2. 确认客户端路径设置正确
3. 检查账号密码是否正确
4. 查看状态栏是否有错误提示

**Q: 游戏客户端启动失败？**
A: 
1. 检查客户端路径是否指向包含 `DNF.exe` 的目录
2. 确认客户端文件完整
3. 尝试以兼容模式运行客户端

---

## 背景设置

**Q: 更换背景后不显示？**
A: 
1. 确认图片格式为 PNG/JPG/WEBP/BMP
2. 图片文件不要过大（建议 < 5MB）
3. 尝试重新添加图片
4. 检查程序目录下 `backgrounds` 文件夹是否有写入权限

**Q: 轮播不生效？**
A: 
1. 确认在背景设置窗口开启了「背景轮播」开关
2. 确认背景列表至少有 2 张图片
3. 检查轮播间隔设置（5-3600秒）
4. 重启登录器后再试

**Q: 预设背景缺失？**
A: 预设背景会在首次启动时自动从素材目录复制。如缺失：
1. 确认 `C:\Users\56518\Downloads\素材` 目录存在 pg1-pg4.webp
2. 删除程序目录下 `backgrounds\preset` 文件夹
3. 重启登录器，会自动重新初始化

## 独立窗口

**Q: 存档/工具窗口打不开？**
A: 
1. 确认主窗口没有被最小化
2. 独立窗口在主窗口居中位置弹出，检查是否被其他窗口遮挡
3. 查看任务栏是否有新窗口
4. 重启登录器后再试

**Q: 独立窗口关闭后主窗口卡死？**
A: 这是已知问题，已在最新版本修复。如仍遇到：
1. 更新到最新版本
2. 不要快速连续打开/关闭独立窗口
3. 如卡死，在任务管理器结束进程后重启

---

## 其他

**Q: 窗口位置不记忆？**
A: 
1. 确认程序目录有写入权限
2. 检查 `window_config.json` 是否被只读锁定
3. 正常关闭程序（不要强制结束）才会保存位置

**Q: 如何恢复默认设置？**
A: 
1. 关闭登录器
2. 删除程序目录下的 `window_config.json`
3. 重新启动，所有设置恢复默认
