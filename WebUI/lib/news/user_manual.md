## 快速开始

1. 启动登录器，确认标题栏右侧显示「服务端已启动」
2. 如未启动，点击导航栏「服务端」→「启动」
3. 输入账号密码，点击「登录」

## 界面说明

### 标题栏

- **左上角**：DNF Logo（hover 放大）
- **中间导航**：服务端、存档、工具、主题
- **右侧**：服务端状态、最小化、关闭

### 主区域

- **登录卡片**：右侧毛玻璃卡片，正面登录/背面设置
- **新闻面板**：左下角，综合/更新/指南三个标签

### 状态栏

- **左侧**：就绪状态 + 通知信息
- **右侧**：版本号

## 功能详解

### 服务端管理

点击导航栏「服务端」弹出菜单：
- **启动**：启动服务端
- **重启**：重启服务端
- **停止**：停止服务端
- **查看日志**：打开服务端日志窗口

### 存档管理

点击导航栏「存档」打开独立窗口：
- 创建存档、恢复存档、删除存档
- 定时备份（可设置间隔）
- 自动备份开关
- 保留数量设置

### 工具中心

点击导航栏「工具」打开独立窗口：
- GM工具
- 账号管理
- PVF校验
- 数据备份
- 客户端补丁
- 服务端管理

### 背景主题

点击导航栏「主题」弹出菜单：
- **上一背景**：切换到上一张
- **下一背景**：切换到下一张
- **高级设置**：
  - 更换背景（打开背景设置窗口）
  - 恢复默认

背景设置窗口功能：
- 背景缩略图网格（最多8张）
- 点击缩略图立即切换
- 添加/删除自定义背景
- 轮播开关 + 间隔设置

## 配置说明

配置文件保存在程序目录下的 `window_config.json`：

```json
{
  "x": 100,
  "y": 100,
  "bg_mode": "single",
  "bg_current": 0,
  "bg_interval": 30,
  "bg_images": [
    {"name": "pg1.webp", "source": "preset"}
  ]
}
```

- `x/y`：窗口位置
- `bg_mode`：single（单张）/ carousel（轮播）
- `bg_current`：当前背景索引
- `bg_interval`：轮播间隔（秒）
- `bg_images`：背景列表

## 常见操作

### 更换背景

1. 点击导航栏「主题」
2. 选择「高级设置」→「更换背景」
3. 在背景设置窗口点击「+」添加图片
4. 点击缩略图立即应用

### 开启轮播

1. 打开背景设置窗口
2. 开启「背景轮播」开关
3. 设置切换间隔（5-3600秒）

### 修改服务端路径

1. 点击登录卡片右上角「设置」
2. 卡片翻转到设置页面
3. 修改客户端路径/服务端路径
4. 点击「确认」保存
